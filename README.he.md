# בוט מסחר קריפטו: מדריך מהיר

**זה לא ייעוץ פיננסי.** מסחר בקריפטו יכול להפסיד את כל הכסף שמושקע בו. לאף אחת מהאסטרטגיות בבוט אין יתרון מוכח. קודם מריצים בקטסט, אחר כך מסחר דמה (Paper) במשך שבועות, ורק אז סכום קטן בכסף אמיתי.

## התקנה

צריך Python 3.11 ומעלה.

```bash
python -m venv .venv
.venv\Scripts\activate              # ב-Mac/Linux: source .venv/bin/activate
pip install -r requirements.txt -r requirements-dev.txt
copy .env.example .env              # ב-Mac/Linux: cp .env.example .env
```

## שלושה צעדים ראשונים

**1. האם יש בכלל יתרון?** מריצים בקטסט על נתונים היסטוריים אמיתיים (הורדה חד-פעמית של כ-3 שנים):

```bash
python main.py backtest --strategy all
```

בסוף מודפס נתיב לדוח HTML בתיקייה `reports`. הדבר הכי חשוב בדוח הוא ההשוואה ל**כניסות אקראיות** עם אותם כללי סיכון. אם האסטרטגיה לא מנצחת בערך 95% מההרצות האקראיות, הכניסות שלה לא טובות ממזל.

**2. איך נראה הדשבורד?** תצוגה עם נתונים מומצאים, בלי בורסה ובלי פקודות:

```bash
python scripts/demo_dashboard.py
```

ואז פותחים בדפדפן את http://127.0.0.1:8765

**3. מסחר דמה:**

```bash
python main.py
```

הדשבורד זמין בכתובת http://127.0.0.1:8765 כל עוד הבוט רץ.

## מה רואים בדשבורד

- הון, רווח/הפסד היום, ירידה מול המגבלה היומית ומול עצירת החירום, וחשיפה פתוחה.
- פוזיציות פתוחות: מרחק לסטופ וליעד, והאם הסטופ יושב בבורסה או רק בתוכנה.
- האות האחרון לכל צמד, וכל החלטה של סוכן הסיכון **כולל הסיבה** (למה נכנס ולמה לא).
- עסקאות סגורות, אירועים ואזהרות, ועקומת הון.
- כפתורים: השהיית כניסות, חידוש, הרצת סבב עכשיו, איפוס עצירת חירום, סגירת כל הפוזיציות, ועצירת הבוט. פעולות מסוכנות מבקשות אישור.

השהיה חוסמת רק **כניסות חדשות**. סטופים ויציאות ממשיכים לעבוד תמיד.

## הגדרות חשובות (`.env`)

| משתנה | ברירת מחדל | מה זה |
| --- | --- | --- |
| `PAPER_TRADING` | `true` | מסחר דמה. כל עוד זה `true` אין פקודות אמיתיות. |
| `STRATEGY` | `trend` | `trend` (פריצת ערוץ בכיוון המגמה) או `legacy` (המקורית). |
| `TIMEFRAME` | `4h` | גודל הנר. |
| `RISK_PER_TRADE` | `0.01` | הפסד של 1% מההון אם הסטופ מתמלא. מקסימום 5%. |
| `MAX_NOTIONAL_PCT` | `0.5` | פוזיציה אחת לא תעבור 50% מההון. |
| `MAX_TOTAL_EXPOSURE_PCT` | `1` | כל הפוזיציות יחד לא יעברו 100% מההון. |
| `DAILY_MAX_LOSS_PCT` | `0.05` | אחרי ירידה של 5% ביום אין כניסות חדשות עד מחר (UTC). |
| `MAX_DRAWDOWN_PCT` | `0.20` | עצירת חירום אחרי ירידה של 20% מהשיא. מתאפסת רק ידנית מהדשבורד. |
| `DASHBOARD_TOKEN` | ריק | חובה ב-Docker. מחרוזת אקראית ארוכה. |

## מעבר לכסף אמיתי (בזהירות)

1. בקטסט, ואחריו שבועות של מסחר דמה.
2. מפתח API **חדש** עם הרשאת מסחר בלבד, **בלי הרשאת משיכה**. עדיף תת-חשבון ייעודי.
3. קודם testnet: `EXCHANGE_SANDBOX=true` ותיקיית נתונים נפרדת: `DATA_DIR=data/live`.
4. אחרי כל כניסה, לבדוק בממשק הבורסה שבאמת נוצרה פקודת סטופ.
5. רק אז: `PAPER_TRADING=false` **וגם** `LIVE_TRADING_CONFIRM=true`.

## Docker

```bash
cp .env.example .env     # להגדיר DASHBOARD_TOKEN
docker compose up -d --build
```

הדשבורד נפתח רק על המחשב המקומי (127.0.0.1:8765), ובכניסה הראשונה מזינים את הטוקן.
